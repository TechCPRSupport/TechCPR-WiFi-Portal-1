TECHCPR WIFI PORTAL RC3 - CLEAN INSTALL

IMPORTANT: Do not permanently delete your existing .env or techcpr.db.

1. Stop Node and Stripe CLI.
2. Back up the entire current project folder.
3. Save these two files separately:
   - .env
   - techcpr.db
4. Empty the project folder, but keep the hidden .git folder if you want to preserve Git history.
5. Copy all RC3 files into the project folder.
6. Copy your saved .env and techcpr.db into the project root.
7. Confirm .env uses BASE_URL, not PUBLIC_BASE_URL, and contains ADMIN_PASSWORD.
8. Run:
   npm install
9. Because node-routeros required a RouterOS 7.21.4 !empty compatibility patch earlier, test before checkout:
   npm run test:mikrotik
10. Start:
   npm start
11. Test:
   http://localhost:3000/status.html
   http://localhost:3000/plans.html
   http://localhost:3000/admin.html
12. Start Stripe CLI and update STRIPE_WEBHOOK_SECRET if it gives you a new whsec value.

SECURITY:
Secrets previously pasted into chat should be rotated before production.

RC3 automatically reapplies the RouterOS 7 !empty compatibility patch after npm install.
